# 效果演示图片

把演示用的 GIF / 截图放在这个目录，然后在仓库根目录的 `README.md` 的
「效果展示」一节里取消对应注释（或直接把表格里的“待补充”替换成图片）。

建议的文件名（README 注释里已经引用）：

| 文件 | 场景 |
| --- | --- |
| `normal-raise.gif` | 普通提升：遮挡窗口渐隐 → 停留 → 在其后方渐显 |
| `large-coverer.gif` | 巨大遮挡窗口（占屏 ≥75% 且比被提升窗口大）→ 对窗口做“停留 + 渐显” |
| `scale-in.gif` | 几乎被完全遮挡（遮挡率 >90%）→ 对窗口做缩放进入 |

录制建议：只截取相关窗口所在的显示器区域，控制在 3–5 秒、几百 KB 以内，
这样 GitHub 上加载较快。
